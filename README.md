# URL Shortener

A simple and efficient URL Shortener that converts long URLs into short, shareable links. Built using HTML, CSS, and JavaScript.

## 🚀 Features

- Shorten long URLs instantly
- Copy shortened URL with one click
- Responsive design
- User-friendly interface
- Fast and lightweight

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
